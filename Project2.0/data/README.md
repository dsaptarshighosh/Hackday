# Zoo Sentinel training data

`zoo_sentinel_synthetic.csv` is generated by `scripts/generate_and_train_zoo_model.py` because the CSV used by the supplied notebook was not included. It contains 2,800 synthetic rows with the notebook's six columns. The hazard targets are generated from a documented toy formula plus random noise; they are not real wildlife or disaster observations and do not reproduce the notebook's reported Random Forest.

Regenerate the CSV and the Node inference artifact with:

```powershell
python scripts/generate_and_train_zoo_model.py
```

The app uses this model for a demonstration probability only. It is not a validated hazard forecast.
